# Security Policy

## Supported Versions

Only the latest tagged release is supported. Older versions do not receive security fixes.

## Reporting a Vulnerability

Do **not** open a public issue or disclose the vulnerability publicly.

Report privately to [avi@babi.uy](mailto:avi@babi.uy) and include:

- The affected version
- The impact
- Reproduction details

You will receive a response as soon as possible.
